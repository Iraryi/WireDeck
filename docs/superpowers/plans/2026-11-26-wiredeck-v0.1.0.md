# WireDeck v0.1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and package `WireDeck v0.1.0`, an open-source Windows desktop & CLI utility that guides laptop-to-console (Xbox Series X|S full parity; PS5/generic lightweight) Gigabit wired direct streaming with 6-layer fault localization, zero-reboot WinNAT toggling, an AI/DSH hot-reload extension surface, and an Inno Setup 6 installer ready for GitHub Release.

**Architecture:** A Python 3.11 core package drives read-only Windows diagnostics and on-demand elevated PowerShell mutations via two PE entrypoints sharing one PyInstaller `--onedir` runtime: `WireDeck.exe` (`WINDOWS_GUI`, Edge WebView2 via `pywebview`) and `wiredeck-cli.exe` (`WINDOWS_CUI`, synchronous UTF-8 JSON CLI & UAC worker). User/AI extensions live as plaintext manifests + scripts under `<data_dir>/extensions/` and safely merge into the 6-layer diagnostic model with timeout and crash isolation.

**Tech Stack:** Python 3.11, `pywebview` (Windows Edge WebView2), `Pillow`, `pytest`, PowerShell 5.1+ (UTF-8), PyInstaller 6 (`--onedir`), Inno Setup 6 (`ISCC.exe`), vanilla HTML/CSS/SVG/JS (zero frontend build tooling).

**Spec:** `d:\New\WireDeck\docs\superpowers\specs\2026-11-26-wiredeck-design.md`

## Global Constraints

- Target OS: Windows 11 / Windows 10 (x64); single version source `APP_VERSION = "0.1.0"` and stable `APP_ID` GUID in `src/wiredeck/version.py`.
- Zero hardcoded machine values (no hardcoded `192.168.8.104`, `PortableSSS`, `Realtek 2.5GbE`, `65428`, or `LightXtreme`-only checks); all adapters/routes/PnP devices are dynamically discovered.
- Minimalist copy discipline on Home screen: card titles ≤ 12 CJK chars, fault descriptions ≤ 28 CJK chars; 4-state status badges (`ok`/`warn`/`fail`/`idle`) always show icon + text (never color alone).
- Strict Windows UAC boundary: GUI & Setup default to non-elevated (`PrivilegesRequired=lowest`); privileged ops use standard Windows UAC `runas` (never UAC bypass).
- Never use Windows ICS (`SharedAccess`) or L2 Network Bridge as sharing backend; only use `New-NetNat` (`WireDeckNat`), and strictly refuse `enable-direct` if any VPN TUN holds `0.0.0.0/0` or ICS is active.
- All `.ps1` files & saved logs use UTF-8 with BOM + CRLF; CLI stdout & JSON files use UTF-8; never include dev tokens, Wi-Fi passwords, or unredacted usernames in exports, repo, or packages.
- Do not bundle third-party streaming executables (XStreamingDesktop); detect existing install or fetch official GitHub Release with SHA-256 verification.
- Do not push to GitHub or publish online Releases until the user explicitly confirms.

## Review Focus

- Non-ASCII and space-containing user profile / install paths (`C:\Users\测试 用户\...`) across Python, PowerShell, PyInstaller, and Inno Setup — must resolve and persist UTF-8 cleanly without codepage corruption (pinned in Tasks 1 & 7).
- Buggy or hostile DSH/AI extension (`check.ps1` infinite sleep, invalid JSON stdout, or `..\..\evil.ps1` path traversal) — must reject traversal, enforce `1..15s` hard timeout, emit `EXT_ERROR`, and never break core L1–L6 diagnostics (pinned in Task 4).
- Active `WireDeckNat` during unprivileged `unins000.exe` uninstall or `disable-direct` / `reset-nic` when `nic_backup.json` is missing/corrupt — must trigger UAC teardown cleanly on uninstall and handle missing backup without crashing or leaving dirty `Forwarding` (pinned in Tasks 3 & 7).
- Multiple physical Ethernet NICs (disabled onboard + active USB NIC) or non-ICS third-party `UDP 53` listener (e.g. SmartDNS/AdGuard) alongside idle Win11 Hyper-V `SharedAccess` — must pick active physical NIC cleanly, downgrade non-ICS `UDP 53` to `warn`, never kill non-ICS processes, and never silently delete foreign `NetNat` (pinned in Tasks 2 & 3).
- Non-elevated headless `wiredeck-cli.exe apply ... --json` without `--elevate` — must exit immediately with code `3` and valid JSON `{ok: false, code: "ADMIN_REQUIRED"}`, never blocking on an unexpected UAC prompt (pinned in Task 5).
